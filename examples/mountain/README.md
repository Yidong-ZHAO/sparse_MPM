# Mountain example

The terrain and release data used in this example are not included in the repository because they exceed GitHub's file size limit.

Please download the terrain data from [here](https://www.dropbox.com/scl/fi/sv22fy52zs22waxw4olfa/mountain_terrain.nvdb?rlkey=yz2krllzrjxlq1h1lbs4wo81u&st=g4kerslr&dl=0) and the release data from [here](https://www.dropbox.com/scl/fi/hg07wdn3h3fc8mas4tdbb/mountain_particles_f0.ply?rlkey=18ac1amq55y0okslgbsp2l8l4&st=0aejaq57&dl=0).

After downloading, please place them in ```/mountain/data/```.
